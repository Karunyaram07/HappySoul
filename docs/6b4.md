# Phase 6B.4 — Krishna AI API Route & Conversation Persistence

**Status: Complete and verified.**

This document is the source-of-truth completion record for Phase 6B.4 of the Happy Soul Krishna AI implementation.

## 1. Overview and Purpose

Phase 6B.4 implements the authenticated Next.js API endpoint `app/api/krishna/route.js` and full conversation/message persistence layer. It connects user authentication, request validation, Phase 6B.2 semantic retrieval, Phase 6B.3 grounded AI reasoning, and database persistence into a single secure HTTP endpoint.

**Execution Boundary:**
- **Implemented:** Next.js App Router POST endpoint, Supabase SSR auth, input validation, conversation creation/reuse, user and assistant message DB persistence, retrieval orchestration, AI reasoning orchestration, structured JSON response, HTTP status mapping (400, 401, 403, 404, 429, 500, 503, 405), and multi-user isolation.
- **Deferred / Excluded (Not in 6B.4):**
  - Frontend UI / Chat interface components (Phase 6B.5).
  - Server-Sent Events (SSE) or streaming responses.
  - Advanced conversation memory / multi-turn history window summarization.
  - Automatic retry / exponential backoff orchestration.
  - Typing indicators or message regeneration UI controls.
  - Production application-level rate limiter service.

## 2. API Endpoint Specification

### Endpoint: `POST /api/krishna`

#### Headers
```http
Content-Type: application/json
Cookie: <supabase-auth-cookies>
```

#### Request Payload
```json
{
  "message": "How can I overcome anxiety and find inner peace?",
  "conversationId": "bfb91576-b144-4ac9-a498-99f2fb283778"
}
```
*Note: `conversationId` is optional. If omitted, a new conversation is created for the authenticated user.*

#### Successful Response (`200 OK`)
```json
{
  "conversationId": "bfb91576-b144-4ac9-a498-99f2fb283778",
  "message": {
    "id": "e4a8990b-6d33-4f90-8451-933e14ad9f92",
    "role": "assistant",
    "content": "Anxiety often arises from clinging to the outcomes of our actions...",
    "citedVerseIds": [
      "9f24e930-7c22-4a0f-b1e1-e123456789ab"
    ],
    "citations": [
      {
        "chapterNumber": 2,
        "verseNumber": 47,
        "verseId": "9f24e930-7c22-4a0f-b1e1-e123456789ab"
      }
    ],
    "createdAt": "2026-10-07T00:15:20.123Z"
  },
  "meta": {
    "isGrounded": true,
    "retrievedCount": 5,
    "citedCount": 1
  }
}
```

## 3. Architecture & Data Flow

```
Authentication (Supabase SSR Session)
        ↓
Input Validation & White-space Normalization (Max 1000 chars)
        ↓
Conversation Handling (Create new or verify user ownership)
        ↓
User Message Persistence (`messages` table, role="user")
        ↓
Phase 6B.2 Retrieval (`retrieveRelevantVerses(supabase, message)`)
        ↓
Phase 6B.3 Reasoning (`generateKrishnaResponse(message, verses)`)
        ↓
Assistant Message Persistence (`messages` table, role="assistant", cited_verse_ids, retrieval_meta)
        ↓
Structured JSON Response (`200 OK`)
```

## 4. Detailed Component Behaviors

### 1. Authentication & Security
- Uses `@/lib/supabase/server` `createClient()` to retrieve the authenticated user from session cookies (`supabase.auth.getUser()`).
- Service-role key is **never** used for handling user requests.
- Returns `401 Unauthorized` (`{ error: "Authentication required.", code: "UNAUTHORIZED" }`) if unauthenticated.
- Strictly respects database Row Level Security (RLS) policies.

### 2. Request Validation
- Enforces HTTP method restriction (POST required; GET, PUT, DELETE return `405 Method Not Allowed`).
- Validates request body presence and JSON formatting.
- Trims and normalizes consecutive whitespace (`normalizedMessage = text.trim().replace(/\s+/g, " ")`).
- Enforces character limit (`MAX_MESSAGE_LENGTH = 1000`).
- Rejects empty, whitespace-only, or over-length strings with `400 Bad Request`.

### 3. Conversation Ownership & Multi-User Isolation
- **No `conversationId` provided:** Creates a new row in `conversations` with `user_id = user.id` and title snippet.
- **`conversationId` provided:** Queries `conversations` with `.eq("id", conversationId).single()`.
- **User Ownership Check:** Verifies `existingConv.user_id === user.id`. If missing or owned by another user, returns `404 Not Found` (`{ error: "Conversation not found.", code: "CONVERSATION_NOT_FOUND" }`). This prevents exposing whether another user's conversation ID exists.

### 4. Database Persistence
- **User Message:** Persisted in `messages` with:
  - `conversation_id`: active conversation UUID
  - `role`: `"user"`
  - `content`: normalized input message
- **Assistant Message:** Persisted in `messages` with:
  - `conversation_id`: active conversation UUID
  - `role`: `"assistant"`
  - `content`: AI answer string
  - `cited_verse_ids`: strictly validated verse UUID array returned by Phase 6B.3
  - `retrieval_meta`: safe JSON metadata containing `matchThreshold`, `matchCount`, `usedThemeFallback`, `model`, `isGrounded`, `retrievedCount`, and `citedCount`. Sensitive provider data and secrets are explicitly excluded.

### 5. Failure & Partial State Handling
- If retrieval or AI generation fails after user message persistence:
  - The legitimate user message remains recorded in `messages` table.
  - No assistant response row is created.
  - The API returns a safe error payload without leaking stack traces or internal secrets.

## 5. Error Responses & Mapping

| Status Code | Error Code | Trigger Condition / Description |
|---|---|---|
| `400` | `INVALID_REQUEST` | Malformed JSON, missing message, empty message, message > 1000 chars, or invalid conversation ID format. |
| `401` | `UNAUTHORIZED` | Unauthenticated user (missing/invalid Supabase session cookie). |
| `404` | `CONVERSATION_NOT_FOUND` | Specified conversation ID does not exist or belongs to another user. |
| `405` | `METHOD_NOT_ALLOWED` | Unsupported HTTP method (GET, PUT, DELETE). |
| `429` | `RATE_LIMIT_EXCEEDED` | Gemini / AI service rate limit triggered. |
| `500` | `GENERATION_FAILED` / `INTERNAL_ERROR` | AI response validation failure, DB write error, or internal runtime error. |
| `503` | `SERVICE_UNAVAILABLE` | Gemini / AI service temporary outage. |
