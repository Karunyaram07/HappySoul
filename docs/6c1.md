# Phase 6C.1.2 — Happy Soul Ambient Motion: Shared Motion Foundation

## 1. Purpose
Introduce a lightweight, reusable, and accessible ambient motion foundation for Happy Soul. These components provide subtle, spiritual, and calming visual cues without causing layout shifts, battery drain, or distractions.

Future phases will integrate these components into the Landing Hero, Chaitanyam AI Drawer, Onboarding Wizard, and Dashboard Welcome Card.

---

## 2. Components Created

### `components/motion/AmbientGlow.jsx`
- **Purpose**: A reusable low-opacity ambient radial glow / background element.
- **Render Engine**: Pure CSS `@keyframes` manipulating `transform: translate3d(...) scale(...)` and `opacity`.
- **Props**:
  - `className` (`string`): Additional CSS classes (default: `""`).
  - `size` (`"sm" | "md" | "lg" | "xl"`): Radial diameter preset (default: `"md"`).
  - `intensity` (`"gentle" | "subtle" | "warm"`): Opacity preset (default: `"subtle"`, ~0.13 opacity).
  - `duration` (`number`): Full breathing cycle in seconds (default: `16`).
  - `variant` (`"accent" | "primary" | "secondary" | "emerald" | "time-aware"`): Color token mapping (default: `"accent"`). `"time-aware"` automatically resolves according to the current local hour:
    - `05:00 - 11:59`: Warm sunlight gold (`accent`)
    - `12:00 - 16:59`: Natural daylight sage (`secondary`)
    - `17:00 - 20:59`: Deep dusk forest (`primary`)
    - `21:00 - 04:59`: Serene quiet obsidian forest (`primary`)
  - `position` (`"center" | "top-left" | "top-right" | "bottom-left" | "bottom-right"`): Anchor alignment preset (default: `"center"`).

### `components/motion/AmbientParticles.jsx`
- **Purpose**: Reusable lightweight decorative particles for future spiritual ambient accents (e.g., drifting flute notes, subtle dots, petals).
- **Render Engine**: Pure CSS `@keyframes` with staggered delays. Cap of 6 DOM nodes maximum.
- **Props**:
  - `count` (`number`): Number of particles (default: `4`, clamped between 2 and 6).
  - `className` (`string`): Container classes (default: `""`).
  - `duration` (`number`): Floating cycle period in seconds (default: `12`).
  - `variant` (`"dots" | "notes" | "petals"`): Particle visual geometry (default: `"dots"`).
  - `color` (`"accent" | "primary" | "secondary"`): Color token (default: `"accent"`).
- **Responsive Behavior**: Extra particles beyond 2 are hidden on small mobile viewports (`hidden sm:block`), and drift amplitude is halved via media queries to preserve battery life.

### `components/motion/BloomEffect.jsx`
- **Purpose**: Discrete, short-lived decorative bloom/ripple accent for milestone interactions (e.g. step completion, "Begin Your Journey" click).
- **Render Engine**: Framer Motion `AnimatePresence` with expanding scale (`0.85` -> `1.35`) and fade (`0.7` -> `0`).
- **Props**:
  - `trigger` (`boolean | any`): Trigger value. Whenever truthy, initiates a single-shot bloom.
  - `variant` (`"emerald" | "accent" | "primary"`): Radial gradient color scheme (default: `"emerald"`).
  - `className` (`string`): Positioning styles (default: `""`).
  - `duration` (`number`): Bloom expansion duration in seconds (default: `0.6`).
  - `onComplete` (`() => void`): Optional callback invoked when the bloom lifecycle ends.

## 3. Reduced Motion Support (`prefers-reduced-motion`)
All three components strictly adhere to accessibility requirements:
1. **`AmbientGlow.jsx`**:
   - `useReducedMotion()` and `@media (prefers-reduced-motion: reduce)` deactivate continuous keyframe animation (`animation: none !important; transform: none !important;`).
   - The soft ambient blur remains peacefully static at base opacity.
2. **`AmbientParticles.jsx`**:
   - When reduced motion is preferred, particles return `null` in React and apply `animation: none !important; opacity: 0 !important;` in CSS.
3. **`BloomEffect.jsx`**:
   - When reduced motion is preferred, scale expansion is removed (`scale` remains `1`), and the animation resolves as a brief, gentle opacity fade (`duration: 0.15s`).

---

## 4. Performance & Architecture
- **Compositor-Only Motion**: Background animations run exclusively on the GPU compositor thread using `transform: translate3d(...) scale(...)` and `opacity`.
- **Zero JS Animation Loops**: No `requestAnimationFrame`, `setInterval`, or React render loops are used.
- **Zero Dynamic Blurs**: Blurs are static (`blur-[80px] sm:blur-[110px]`); filter parameters are never animated on every frame.
- **Zero External Dependencies**: Implemented using existing `framer-motion`, `lucide-react`, and Tailwind CSS setup.

---

## 5. Accessibility
- All decorative containers enforce `aria-hidden="true"` and `role="presentation"`.
- All decorative containers enforce `pointer-events-none` to guarantee zero interference with user clicks, taps, or keyboard focus.
- Layout flow is completely preserved using `absolute inset-0 overflow-hidden select-none`.
