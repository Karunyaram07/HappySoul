## 3. Provider & State Orchestration (`components/krishna/ChaitanyamProvider.jsx`)

The `ChaitanyamProvider` owns all client-side chat state and exports the `useChaitanyam()` hook:

### State Surface:
- `isOpen` (boolean) — Drawer panel visibility.
- `messages` (array) — In-memory chat message history (`id`, `role`, `content`, `citedVerseIds`, `citations`, `createdAt`, `isGrounded`).
- `conversationId` (string | null) — Current active server conversation UUID.
- `loading` (boolean) — Processing/generation state.
- `error` (string | null) — User-facing error message.
- `lastFailedText` (string | null) — Cached prompt text for single-click retries.

### Methods:
- `openChat()` / `closeChat()`
- `startNewConversation()` — Increments generation ref, aborts active API request, clears in-memory messages and `conversationId`.
- `sendMessage(text)` — Performs client validation (max 1000 chars), optimistically appends user message, calls `sendChaitanyamMessage()`, updates state.
- `retry()` — Resends `lastFailedText` without creating duplicate user message bubbles.

### Security & Stale Response Protection:
- **Sign-Out & User Reset:** Automatically resets all messages, conversation IDs, loading states, and error alerts when `userId` changes or Supabase emits `SIGNED_OUT`.
- **No `localStorage` Persistence:** Messages are stored in-memory during active session; persistent history remains server-side.
- **Stale Generation Ref Guard (`requestGenRef`):** Every new conversation or reset increments a request generation counter. When an API response completes, it verifies `currentGen === requestGenRef.current`. Stale responses are discarded immediately so old answers never bleed into newly created conversations.
- **Duplicate Send Guard (`isSubmittingRef`):** Prevents double-clicks or rapid Enter keystrokes from generating duplicate requests.

## 4. API Client Helper (`components/krishna/api.js`)

Calls `POST /api/krishna` with an optional `AbortSignal` and client-side 25-second timeout controller (`AbortSignal.any`).

### Error Mapping Contract:

| Status Code | User-Facing Message |
|---|---|
| `400` | "Please enter a valid message." |
| `401` | "Please sign in again to continue." |
| `404` | "This conversation is no longer available." |
| `429` | "Chaitanyam is busy right now. Please try again shortly." |
| `500` | "Something went wrong. Please try again." |
| `503` | "Chaitanyam is temporarily unavailable. Please try again later." |
| `408` (Timeout) | "Chaitanyam is taking longer than expected. Please try again." |

*Raw Gemini errors, stack traces, API keys, and database credentials are strictly suppressed.*

- Positioned fixed at `bottom-6 right-6 z-40`.
- Styled with forest green gradient, `Sparkles` icon, subtle glowing aura, and responsive layout.

### 2. `ChaitanyamDrawer.jsx` (Slide-Over Panel)
- Hand-rolled accessible dialog using `framer-motion` (`AnimatePresence`) and Tailwind CSS (`z-[60]`).
- Desktop: Right-side slide-over (`w-full sm:w-[440px]`).
- Accessibility: `role="dialog"`, `aria-modal="true"`, focus management, Esc key listener, and `document.body` scroll locking.

### 3. `ChaitanyamHeader.jsx`
- Displays Chaitanyam AI branding, "Gita Companion" badge, and spiritual subtitle: *"Your companion for wisdom, reflection & inner peace."*.
- Contains "New Chat" reset button (`RefreshCw`) and single Close button (`X`).

### 4. `ChaitanyamMessageList.jsx`
- **Welcome / Empty State:** Displays warm first-name greeting (*"Namaste, [FirstName] 🙏"*), companion intro, and 4 starter prompts:
  - *"How can I deal with overthinking?"*
  - *"How can I stay calm during difficult times?"*
  - *"What does the Bhagavad Gita say about fear?"*
  - *"How can I stay focused on my goals?"*
- **Message Rendering:** Plain-text line break preservation (`whitespace-pre-wrap`) and safe bold formatting (`**text**`) without `dangerouslySetInnerHTML` or external markdown dependencies.
- **Grounding Metadata:** If `isGrounded === false`, displays subtle notice: *"🌿 General guidance, not tied to a specific verse."*.
- **Static Disclaimer:** Footer disclaimer: *"Guidance inspired by the Bhagavad Gita — not therapy or medical advice."*.

### 5. `ChaitanyamInput.jsx`
- Textarea with auto-height expansion (up to 120px) and Enter key submit handler (Shift+Enter for newline).
- Live character counter: `currentLength / 1000` (`.length` matching 6B.4 validation).
- Prevents sending messages over 1000 characters or empty whitespace.

### 6. `GitaCitationBadge.jsx`
- Non-clickable scripture reference chip (e.g. `Bhagavad Gita 2.47`) constructed from API response `{ chapter, verse }`.

### 7. `QuickActions.jsx` Integration
