## 1. Purpose

When a user opens a dedicated Bhagavad Gita verse detail page (e.g. `/dashboard/gita/2/47`), they view canonical Sanskrit text, IAST Roman transliteration, Sivananda English translation, and theological commentaries.

Phase 6B.9 introduces **AI-Powered Gita Verse Essence**:
An on-demand, isolated, lightweight section that distills the core practical and spiritual meaning of *that specific verse* directly into the user's preferred onboarding language (e.g. Telugu, Hindi, Tamil, Kannada, Malayalam, or English).

---

## 2. Architecture & Data Flow

```text
[Browser: /dashboard/gita/[chapter]/[verse]]
       │
       │ 1. Mounts VerseEssence Client Component
       │ 2. Sends POST /api/gita/essence { chapter, verse }
       ▼
[Server Route Handler: app/api/gita/essence/route.js]
       │
       ├── 3. Validates session with supabase.auth.getUser() (401 if unauthenticated)
       ├── 4. Validates chapter (1-18) and verse (>= 1) integer bounds (400 if malformed)
       ├── 5. Queries profiles.preferred_language server-side (.eq("id", user.id))
       ├── 6. Queries canonical verse from public.gita_verses (Sanskrit, transliteration, translation)
       │      (Embeddings are NEVER selected or retrieved)
       ├── 7. Invokes isolated generator: lib/gita/essenceGenerator.js
       │      (Primary model: gemini-flash-lite-latest, temperature: 0.25, maxTokens: 250)
       │
       ▼
[JSON Response: { chapter, verse, language, essence }]
       │
       ▼
[Browser: Updates VerseEssence Card smoothly with Indic typography]
```

### Security Boundary:
The client browser sends **strictly**:
```json
{
  "chapter": 2,
  "verse": 47
}
```
The browser **never** sends:
- Sanskrit text
- English translation
- Commentary
- Prompt text
- Target language parameter

The server independently and securely resolves the authenticated user's `preferred_language` and queries the canonical verse from Supabase. Prompt injection through client-controlled scripture is impossible.

## 3. Dedicated Generator (`lib/gita/essenceGenerator.js`)

An isolated module completely decoupled from the Chaitanyam chat RAG engine (`lib/krishna/generator.js`):

- **Primary Model:** `gemini-flash-lite-latest`
- **Fallback Model:** `gemini-3.1-flash-lite-preview`
- **Temperature:** `0.25` (Low temperature for faithful, grounded distillation)
- **Max Tokens:** `250`
- **Response MIME Type:** `text/plain`
- **Script Directives:**
  - **English:** English Latin script
  - **Telugu:** Telugu script (తెలుగు లిపి)
  - **Hindi:** Devanagari script (देवनागरी लिपि)
  - **Tamil:** Tamil script (தமிழ் எழுத்துக்கள்)
  - **Kannada:** Kannada script (ಕನ್ನಡ ಲಿపి)
  - **Malayalam:** Malayalam script (മലയാള ലിപി)

## 4. Route Handler (`app/api/gita/essence/route.js`)

- **Method:** `POST`
- **Path:** `/api/gita/essence`
- **Request:**
  ```json
  { "chapter": 2, "verse": 47 }
  ```
- **Response (200 OK):**
  ```json
  {
    "chapter": 2,
    "verse": 47,
    "language": "Telugu",
    "essence": "ఈ పవిత్ర శ్లోకం ప్రకారం, మానవునికి కర్మ చేయుట యందే అధికారము కలదు గాని, ఎన్నడూ దాని ఫలితాలపై హక్కు లేదు..."
  }
  ```
- **Error Codes:**
  - `401 Unauthorized`: Unauthenticated request
  - `400 Bad Request`: Malformed or out-of-bounds chapter/verse parameters
  - `404 Not Found`: Verse coordinates do not exist in database
  - `429 Too Many Requests`: Gemini rate-limit reached
  - `502 Bad Gateway`: AI service generation failure

## 5. UI States & Component (`components/gita/VerseEssence.jsx`)

Mounted on `app/dashboard/gita/[chapter]/[verse]/page.js` right after the Transliteration card and before Translation.

1. **Loading State:**
   - Calm card matching the warm alabaster / amber palette.
   - Pulsing `Sparkles` icon with text: `"Reflecting on this verse..."`.
2. **Success State:**
   - Heading: `"Verse Essence"` with a language badge (e.g. `Telugu`, `Hindi`, `English`).
   - Relaxed line height (`leading-relaxed sm:leading-loose text-sm sm:text-base`) tailored for Indic diacritics.
3. **Failure State (Non-Blocking):**
   - Renders a discreet notice: *"Essence reflection is temporarily resting. The canonical translation and commentary are available below."*
   - Includes a `"Retry"` button to re-trigger the generation.
   - The rest of the verse page remains 100% operational.

## 9. Known Limitations (Phase 6B.9 V1)

1. **No Persistence / Caching:** V1 generates the Essence on demand each time the page loads. Reloading the page or revisiting the verse re-invokes the API. Database caching or persistent localization tables are intentionally deferred to future phases.
2. **Translation Scope:** Only the Essence section is localized via AI in V1; canonical Sivananda translations and commentaries remain in English.
